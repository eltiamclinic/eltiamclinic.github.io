برای ورود، «کلید دسترسی» گیت‌هاب را وارد کنید. این کلید فقط روی همین گوشی ذخیره می‌شود.

کلید را از کجا بگیرم؟
  1. در گیت‌هاب: Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Resource owner: eltiamclinic. Expiration: یک سال.
  3. Repository access: Only select repositories ← eltiamclinic.github.io.
  4. Permissions ← Repository ← Contents: Read and write.
  5. Generate token، کلید را کپی و این‌جا وارد کنید.
